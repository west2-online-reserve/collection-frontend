# 目前阶段总结
## 项目介绍
仓库地址：https://github.com/Rin-windsky/my-blog

博客网址：https://rin-windsky.github.io/my-blog/

必做功能都完成了，加分项只完成了 `GitHub Pages` 部署，但是剩下的后续也会尽快逐一完成。

整体分成三个部分，首页和文章还有关于我。首页卡片点击读全文就会跳转到文章页看到整篇文章。

通过媒体查询实现了响应式。另外采取AI的建议可能也是行业规范，写了一些供屏幕阅读的属性（说是为了视障人士）。

主色选的是绿色（以后想放一张绿色的背景）。







## 学到了什么
目前的代码基本都是自己写的，基本都能看得懂，初步学会了 `css` `html` `js` 这三种前端基本语言。

动画方面知道了 `transition` 和 `@keyframes` ，两种实现方式，前者是点对点的过渡动画，后者可以做多段动画。

学会了使用 `f12` 开发者工具这个浏览器自带的功能。
## 遇到的问题
目前存在的问题还是蛮多的。
### 设计上
- 现在文章页面只有在首页的卡片点读全文才有内容显示，要是单独点击导航栏上的文章会显示没找到，最简单的就是把那个导航栏上的文章隐藏掉，但我还在想有没有什么更好的办法（把所有的卡片移到文章里去，首页就只欢迎，背景做好看点）。
- 目前整个博客还是太单调了，背景什么的都要安排上。想要背景动起来像电脑壁纸一样该怎么操作呢？
### 技术上
- 当内容超出屏幕的长度的时候右边就会自动加上一个滚动条，但是会挤压整个页面空间让内容给他让步。我都想法是能不能让这个滚动条浮在内容上。
- 深色模式的动画加得太乱了，虽然看起来没什么问题，但是这样的话代码质量会不高。我发现写前端代码，越往后写越乱，虽然各个模块和文件各司其职，但是随着标签的属性的增加和功能上的完善就会常常找一个东西找好久（终于明白为啥要写注释了）。
- 现在的文章是硬编码，那正常的项目里面是什么样的呢，是docx或者pdf文件吗，还有markdown渲染，我现在的文章感觉就接近markdown了，但是感觉这样手动一行一行地调很麻烦，难道说markdown渲染就是为了解决这个问题？
## 对未来的想法
前端不是终点，还得尽快往后学，并且养成良好的学习习惯，平衡各种杂事。
